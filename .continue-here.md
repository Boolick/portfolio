## Critical Anti-Patterns (do NOT repeat these)
- Do NOT add npm dependencies for Telegram SDK — zero-dependency client and server architecture is strictly maintained.
- Do NOT use structural emojis in bot commands, buttons, or window titles — preserve Constructivist / Swiss typography discipline.
- Do NOT hardcode credentials or commit `.env.local` — tokens must be provided via Netlify env vars or `--env-file`.
- Do NOT use `ref.current = ...` during React component render — use `useEffect` or standard dependencies to comply with React 19 / ESLint `react-hooks/refs`.
